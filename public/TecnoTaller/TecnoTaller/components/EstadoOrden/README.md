# EstadoOrden

Etiqueta en píldora con el ícono y el nombre de uno de los siete estados de una orden de servicio; colores fijos (ver README, "El sistema de estados"). Úsala en tablas del panel, tarjetas del portal y encabezados de la orden. El consumidor pasa `estado`: `ingresado`, `revision`, `repuesto`, `reparacion`, `reparado`, `listo` o `entregado`. Nunca cambies el texto ni la uses como botón.
