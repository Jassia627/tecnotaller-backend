# Button

Botón de acción del portal y del panel; un solo **primary** (`blue-strong`) por vista, para la acción a la que sirve la pantalla ("Crear orden", "Agendar servicio"). `secondary` para lo demás; `danger` para anular una orden o eliminar un repuesto, siempre con confirmación. Verbo primero, frase corta, sin mayúsculas sostenidas. El consumidor pasa `onClick`, `type` y `disabled` como en un `<button>`.
